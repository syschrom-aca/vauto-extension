Setup Instructions
  1. Load this extension in Chrome via chrome://extensions (Developer mode)
  2. Navigate to any vAuto inventory page — VINs are auto-detected
  3. Configure your Microsoft Fabric endpoint in the Settings tab
  4. The content script reads the active VIN and fetches data from Fabric
📡
Fabric API Endpoint

The extension calls your Fabric view/table at:

GET {FABRIC_ENDPOINT}/vehicle/{VIN}

Configure the base URL in Settings. Auth token is sent as Bearer in the Authorization header.

📦
Data Warehouse Sync

To keep vehicle data fresh from your warehouse:

  • Create a scheduled job in Fabric to materialise a vehicle view
  • Expose the view via Fabric REST API or Azure API Management
  • Set refresh interval to match your pricing cadence
  • Map VIN as the primary key in the view/table
